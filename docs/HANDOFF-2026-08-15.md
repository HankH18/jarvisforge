rejects all ~21 legacy `cd backend && ...` verify strings, so most already-closed
tickets can never be re-claimed either.

## 5. Working conventions this session established

- **`.claude/monitor/STACK.md`** is the working ticket stack. `docs/tickets.json` is
  read-only *and* guard-denied, so watchdog findings cannot be added to the task graph;
  they land there instead, keyed for dedup. `.claude/monitor/**` is in `META_ALLOW`,
  hence writable.
- **`.claude/NEEDS_HUMAN.md` is append-only.** A full rewrite by another agent destroyed
  the blocker report once; there is now a banner saying so.
- **Reproduce before dispatching.** The watchdog filed two findings with specific
  reproduced failure counts ("7/10", "1/2") that did **not** reproduce — both suites
  passed at HEAD. Dispatching agents to "repair" them would have damaged two working
  harnesses. A third filing named `App.tsx:72` as a sign-out call site; it is inside
  `handleJoin`. The findings keep being real; the specifics attached to them keep not
  being. Always run the named command yourself first.
- **Never `git stash` in this checkout.** One agent did, while two others held
  uncommitted work. It merged cleanly, but only by luck.
- **Read installed source, not docs.** The LiveKit `DUPLICATE_IDENTITY` behaviour and
  the worker's dispatch semantics were both settled by reading
  `backend/.venv/.../livekit/`. This has now paid off four times in this repo.

## 6. The trap that nearly fired this session

A fix landed that gave each session a unique LiveKit identity — correct, and it closed
a real eviction bug. But `worker.py:_resolve_user_id` feeds mem0's namespace key and
read the participant identity **raw**, so for a while the working tree silently had
per-session memory namespaces: cross-session memory broken for every user, worse than
the bug being fixed, with all 511 tests green.

It was caught only because the implementing agent said plainly that it had stopped at
its scope boundary mid-fix. Both halves are now in one commit (`26009e9`) on purpose —
splitting them would have put a memory-breaking commit in history.

The lesson is the one this repo keeps re-teaching: **green is evidence about the test,
not about the product.** Before believing a capability works, exercise it through the
real assembled path.
